# Contraste de transferencia a H146

Se aplica el mismo método de inversión desde los terminales a la ventana H=146 con D3≤146 y supuesto fallo D5≥378. Se conserva el mismo origen, sus relojes y los aditivos. Se permite una ejecución exacta con el umbral nuevo, sin órbitas ni un barrido de valores iniciales. Si aparece una fuente se detiene y audita. El caso D3>146 queda fuera de esta ejecución.
